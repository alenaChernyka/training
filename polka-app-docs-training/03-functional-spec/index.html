    Полка. Функциональная спецификация

    Назначение документа

    Этот документ описывает функциональность приложения и сценарии его использования. Документ строится на основе брифа и глоссария и детализирует, как именно работает каждая функция, входящая в текущую версию продукта.

    Список функций

    • Создание запаса
    • Добавление дополнительных полей
    • Просмотр всех запасов
    • Редактирование запаса
    • Фильтрация по состоянию
    • Фильтрация по категории
    • Фильтрация по состоянию и категории одновременно
    • Удаление запаса
    • Поиск по названию

    Создание запаса

    Описание

    Пользователь быстро фиксирует в приложении новый запас и указывает его текущее состояние, не заполняя дополнительные поля.

    Правила и поведение

    При нажатии на кнопку добавления запаса открывается форма запаса. В ней нужно заполнить 2 обязательных поля:

    • Название

      • тип: текст с ограничением 50 символов
      • обязательность: да
      • по умолчанию: плейсхолдер
      • уникальность: название должно быть уникальным среди всех запасов.

    • Состояние

      • тип: список, одно из значений: «много», «мало», «нет»
      • обязательность: да
      • по умолчанию: «много»

    Дополнительные поля необязательны для заполнения на этом шаге и по умолчанию скрыты, но пользователь может раскрыть их и заполнить прямо здесь же, при создании запаса.

    Дальше нужно сохранить созданный запас. Форма запаса закроется, а новый запас появится в списке запасов.

    Форму запаса можно закрыть без сохранения. Тогда запас не сохранится, даже если пользователь заполнил поля.

    Сценарий использования

    1. Пользователь нажимает кнопку добавления запаса.
    2. Открывается форма запаса.
    3. Пользователь вводит название вместо плейсхолдера.
    4. При необходимости меняет состояние.
    5. Нажимает кнопку сохранения.
    6. Запас создаётся и появляется в общем списке запасов.

    Граничные случаи

    Если пользователь не ввел название, кнопка сохранения будет неактивна.

    Если пользователь ввел неуникальное название, кнопка сохранения становится активной, но при попытке ее нажать появляется предупреждение с выбором из двух вариантов: - Если пользователь подтверждает переход к существующему запасу — открывается его форма, новый запас не создаётся.
    - Если пользователь отклоняет — предупреждение закрывается, в поле стоит плейсхолдер.

    Если пользователь нажал на выбранное состояние еще раз, ничего не происходит.

    Связь с другими функциями

    Созданный запас сразу отображается в списке запасов и учитывается в фильтрации по состоянию.

    При создании запаса можно добавить и заполнить дополнительные поля.

    Добавление дополнительных полей

    Описание

    Пользователь добавляет и заполняет дополнительные поля для запаса из предложенного списка: категория, количество, срок годности, комментарий.

    Правила и поведение

    В форме запаса можно раскрыть и заполнить дополнительные поля:

    • Категория

      • тип: текст с возможностью выбора одного значения из ранее созданных пользователем категорий или ввода нового с ограничением 20 символов
      • обязательность: нет
      • по умолчанию: ничего не выбрано
      • уникальность: категория должна быть уникальной, две категории с одинаковым названием нельзя создать
      • дополнительно: категорию можно удалить в списке созданных категорий прямо в дополнительном поле

    • Количество

      • тип: текст с ограничением 20 символов
      • обязательность: нет
      • по умолчанию: ничего не выбрано
      • уникальность: нет

    • Срок годности

      • тип: дата
      • обязательность: нет
      • по умолчанию: ничего не выбрано
      • уникальность: нет

    • Комментарий

      • тип: текст с ограничением 200 символов
      • обязательность: нет
      • по умолчанию: ничего не выбрано
      • уникальность: нет

    Дальше нужно сохранить запас. Информация из дополнительных полей будет отображаться в списке запасов.

    Форму запаса с дополнительными полями можно закрыть без сохранения. Если это уже существующий запас, информация из заполненных дополнительных полей не сохранится. Если запас еще не создан, он не сохранится в списке запасов.

    Сценарий использования

    1. Пользователь создает новый запас или редактирует существующий.
    2. Раскрывает список дополнительных полей.
    3. Заполняет любое или все дополнительные поля на свое усмотрение.
    4. Нажимает кнопку сохранения.
    5. Информация из дополнительных полей появляется в списке запасов.

    Граничные случаи

    Если пользователь вводит название уже существующей категории, подставляется существующая категория. Дублирующие названия создать нельзя. Пробелы и разный регистр букв не учитываются: нельзя создать две категории «аптечка» и «Аптечка».

    Если значение любого дополнительного поля состоит только из пробелов, оно считается незаполненным. Новая категория при этом не создается, количество и комментарий не сохраняются.

    Если у категории не осталось ни одного запаса, она сохраняется в фильтрации по категориям.

    Если пользователь удаляет категорию, у которой есть запасы, поле «Категория» у таких запасов становится пустым.

    Связь с другими функциями

    Если пользователь ввел первую категорию в дополнительном поле «Категория», то при просмотре всех запасов появляется фильтрация по категории из двух пунктов: название созданной категории и текст для пустой категории.

    Если пользователь ввел новую категорию в дополнительном поле «Категория», то при просмотре всех запасов в фильтрацию по категории добавляется новый пункт.

    Если пользователь удалил категорию, то она пропадает из фильтрации по категории.

    Просмотр всех запасов

    Описание

    Пользователь смотрит список своих запасов.

    Правила и поведение

    При загрузке приложения открывается список всех запасов, отсортированных по критерию, который пока не определен, без применения фильтров. Есть возможность сбросить применённый фильтр по состоянию и вернуться к просмотру всех запасов.

    Рядом с названием каждого запаса отображается индикатор состояния и категория, если она заполнена. Также показывается либо информация из полей «Количество» и «Срок годности» (если заполнено хотя бы одно из них), либо «Комментарий», если он заполнен. Между этими вариантами можно переключаться. Переключение отдельное у каждого запаса. По умолчанию показываются поля «Количество» и «Срок годности» и переключатель на комментарий, если он заполнен.

    Сценарий использования

    1. Пользователь открывает приложение или сбрасывает фильтр.
    2. Открывается список всех запасов, пользователь может его прокручивать.

    Граничные случаи

    Если у запаса не заполнено ни одно из полей «Количество», «Срок годности», «Комментарий», переключатель не показывается.

    Если у запаса нет комментария, переключатель не показывается.

    Если поля «Количество» и «Срок годности» пустые, а «Комментарий» заполнен — показывается «Комментарий» без переключателя.

    Если пользователь не создал ни одного запаса или удалил все запасы, на странице появляется текст.

    Связь с другими функциями

    Список пополняется при создании запасов и сокращается при удалении. Служит основой для фильтрации по состоянию и категории и поиска по названию — все они работают поверх этого списка.

    Редактирование запаса

    Описание

    Пользователь редактирует уже созданный запас, меняет название, состояние, добавляет или меняет категорию, количество, срок годности или комментарий.

    Правила и поведение

    При просмотре всех запасов можно нажать на любой из них, тогда откроется форма этого запаса.

    Можно поменять название и состояние запаса так же, как при создании запаса.

    Все заполненные дополнительные поля в форме открыты, не заполненные — скрыты. Можно поменять информацию в открытых полях или раскрыть и заполнить скрытые, как при добавлении дополнительных полей.

    Если пользователь очищает поле «Название» полностью, кнопка сохранения становится неактивна, как при создании запаса.

    Можно удалить информацию из всех необязательных полей.

    Сценарий использования

    1. Пользователь нажимает на запас в списке запасов.
    2. Открывается форма запаса.
    3. Пользователь по желанию меняет информацию в открытых заполненных обязательных и дополнительных полях, раскрывает незаполненные дополнительные поля и заполняет их или удаляет любую информацию из дополнительных полей.
    4. Нажимает на кнопку сохранения.
    5. Запас редактируется — изменения отображаются в списке запасов. Если категория запаса была добавлена, изменена или удалена, соответствующие изменения отражаются в списке категорий в фильтре.

    Граничные случаи

    Если пользователь меняет название на уже существующее у другого запаса, применяется то же предупреждение, что при создании запаса. Если пользователь возвращает название без изменений (оставляет как было), предупреждение не появляется, это не считается конфликтом.

    Если пользователь очищает поле «Категория», категория остаётся доступной для выбора у других запасов, даже если этот запас был последним у этой категории.

    Если пользователь очищает поле «Количество», «Срок годности» или «Комментарий», значение удаляется, при следующем открытии формы редактирования поле снова отображается как незаполненное.

    Если пользователь закрывает форму без сохранения, изменения не применяются, запас остаётся в том виде, в каком был до открытия формы.

    Связь с другими функциями

    Название и состояние редактируются по тем же правилам, что при создании запаса.

    Дополнительные поля редактируются по тем же правилам, что при добавлении дополнительных полей, включая логику совпадения и удаления категории.

    Изменения сразу отражаются в просмотре всех запасов и учитываются в фильтрации по состоянию и фильтрации по категории.

    Удаление запаса доступно из этой же формы — см. удаление запаса.

    Фильтрация по состоянию

    Описание

    Пользователь фильтрует список запасов, чтобы увидеть только запасы с определенным состоянием.

    Правила и поведение

    Пользователь выбирает одно из трех состояний — «много», «мало» или «нет». В списке остаются только запасы с выбранным состоянием. Выбранное состояние можно сменить на другое; в моменте активен только один фильтр по состоянию.

    Сценарий использования

    1. Пользователь выбирает состояние в панели фильтра.
    2. Список запасов обновляется — остаются только запасы с этим состоянием.
    3. Пользователь может выбрать другое состояние или сбросить фильтр (см. просмотр всех запасов).

    Граничные случаи

    Если для выбранного состояния нет ни одного запаса — список отображается пустым, дополнительный текст не показывается.

    Связь с другими функциями

    Работает поверх списка из просмотра всех запасов. Сброс фильтра возвращает к поведению из этого же раздела. Комбинируется с фильтрацией по категории — см. отдельную функцию «Фильтрация по состоянию и категории одновременно».

    Фильтрация по категории

    Описание

    Пользователь фильтрует список запасов, чтобы увидеть только запасы с определенной категорией.

    Правила и поведение

    Фильтр по категории появляется только после того, как создана хотя бы одна категория (см. добавление дополнительных полей).

    Пункты фильтра — каждая созданная категория и отдельный пункт «Без категории», который появляется вместе с первой созданной категорией.

    Пользователь выбирает одну категорию за раз. Повторное нажатие на уже выбранную категорию снимает фильтр — в отличие от фильтра по состоянию, здесь нет отдельного пункта «все».

    Также, пока выбрана категория, доступна отдельная кнопка сброса фильтра. Кнопка появляется только когда категория выбрана; пока фильтр не применен, кнопки нет.

    Если выбранная в качестве фильтра категория удаляется, фильтр автоматически сбрасывается.

    Сценарий использования

    1. Если создана хотя бы одна категория, пользователь видит панель фильтра по категории.
    2. Выбирает категорию или пункт «Без категории».
    3. Список запасов обновляется — остаются только запасы с этой категорией (или без категории). Появляется кнопка сброса фильтра.
    4. Пользователь может выбрать другую категорию.
    5. Чтобы сбросить фильтр, пользователь нажимает повторно на выбранную категорию или нажимает кнопку сброса фильтра.

    Граничные случаи

    Если для выбранной категории нет ни одного запаса — список отображается пустым, дополнительный текст не показывается.

    Если выбранная в качестве фильтра категория удаляется, фильтр автоматически сбрасывается.

    Связь с другими функциями

    Работает поверх списка из просмотра всех запасов. Список категорий формируется и обновляется в добавлении дополнительных полей и редактировании запаса. Комбинируется с фильтрацией по состоянию.

    Фильтрация по состоянию и категории одновременно

    Описание

    Пользователь одновременно применяет фильтр по состоянию и фильтр по категории, чтобы увидеть запасы, подходящие сразу под оба условия.

    Правила и поведение

    Оба фильтра могут быть активны одновременно и работают независимо друг от друга. Список запасов показывает пересечение — только те запасы, которые соответствуют и выбранному состоянию, и выбранной категории. Если активен только один из фильтров, применяется только он. Если ни один не активен, список не ограничен.

    Единой кнопки сброса сразу обоих фильтров нет — каждый фильтр сбрасывается отдельно, своим способом (см. фильтрация по состоянию и фильтрация по категории).

    Сценарий использования

    1. Пользователь применяет фильтр по состоянию.
    2. Дополнительно применяет фильтр по категории.
    3. Список обновляется, показывая только запасы, подходящие под оба условия.
    4. Пользователь сбрасывает любой из фильтров по отдельности — список обновляется соответственно оставшемуся фильтру или показывает все запасы, если сброшены оба.

    Граничные случаи

    Если под оба условия не подходит ни один запас — список отображается пустым, дополнительный текст не показывается.

    Связь с другими функциями

    Комбинация фильтрации по состоянию и фильтрации по категории; самостоятельной логики, кроме правила пересечения, не содержит.

    Удаление запаса

    Описание

    Пользователь безвозвратно удаляет запас, который больше не нужно вести в учете.

    Правила и поведение

    Удалить запас можно только из формы редактирования уже существующего запаса. При создании нового запаса действие недоступно.

    Удаление необратимо — восстановить удаленный запас невозможно. Перед удалением пользователь должен подтвердить действие в отдельном предупреждении.

    Если у удаляемого запаса была заполнена категория, категория не удаляется вместе с запасом — она остается доступной для выбора у других запасов, даже если этот запас был последним в этой категории.

    Сценарий использования

    1. Пользователь открывает форму редактирования существующего запаса.
    2. Нажимает на действие удаления.
    3. Появляется предупреждение с просьбой подтвердить необратимое удаление.
    4. Пользователь подтверждает или отменяет действие.
    5. При подтверждении — запас удаляется, форма закрывается, запас пропадает из списка запасов. При отмене — предупреждение закрывается, запас не удаляется, пользователь остается в форме редактирования.

    Граничные случаи

    Граничных случаев нет.

    Связь с другими функциями

    Доступно только через редактирование запаса. Удаленный запас пропадает из просмотра всех запасов и перестает учитываться в фильтрации по состоянию и фильтрации по категории.

    Поиск по названию

    Описание

    Пользователь ищет запас по названию, чтобы быстро проверить его наличие, не листая весь список.

    Правила и поведение

    Поиск ищет совпадение с начала любого слова в названии запаса, без учета регистра. Например, запрос «паста» находит запас «Зубная паста», так как второе слово названия начинается с «паста».

    Поиск игнорирует активные фильтры по состоянию и категории — ищет по всем запасам независимо от них (см. решение в Журнале решений).

    При начале поиска (ввод первого символа в строку поиска) активные фильтры по состоянию и категории сбрасываются.

    Сценарий использования

    1. Пользователь начинает вводить текст в строку поиска — ранее примененные фильтры по состоянию и категории сбрасываются.
    2. Список обновляется, показывая только запасы, в названии которых есть слово, начинающееся с введенного текста (без учета регистра).
    3. Пользователь очищает поисковый запрос.
    4. Список возвращается к полному перечню запасов, без фильтров.

    Граничные случаи

    Если по запросу не найдено ни одного запаса — показывается текст.

    Связь с другими функциями

    Работает поверх списка из просмотра всех запасов. Начало поиска сбрасывает фильтрацию по состоянию и фильтрацию по категории.
